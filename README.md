# Forest Fire Detection using Deep Learning (CNN)

This project uses a Convolutional Neural Network (CNN) to detect the presence of fire in images. The model is built and trained using TensorFlow/Keras within a Jupyter Notebook environment.

## Project Overview

The goal is to classify images into two categories: 'fire' or 'nofire'. This is achieved by:
1.  Downloading and preparing a dataset of fire and non-fire images.
2.  Building a CNN model suitable for image classification.
3.  Training the model on the prepared dataset.
4.  Evaluating the model's performance on a separate test set.
5.  Saving the trained model for future use.
6.  Providing a function to predict on new images using the saved model.

## Dataset

*   **Source:** The Wildfire Dataset from Kaggle by El Madafri (`elmadafri/the-wildfire-dataset`).
*   **Loading:** The dataset is automatically downloaded using the `kagglehub` library within the notebook.
*   **Structure:** The dataset is pre-split into `train`, `val` (validation), and `test` directories, each containing subdirectories for the `fire` and `nofire` classes.
*   **Preprocessing:** Images are resized to 150x150 pixels. Pixel values are rescaled to the [0, 1] range.
*   **Augmentation:** The training data uses `ImageDataGenerator` for augmentation (rotation, shifts, shear, zoom, horizontal flip) to improve model robustness. Validation and test data are only rescaled.

## Model

*   **Type:** Convolutional Neural Network (CNN)
*   **Framework:** TensorFlow / Keras
*   **Architecture:**
    *   Input Layer (150x150x3)
    *   Conv2D (32 filters) + MaxPooling2D
    *   Conv2D (64 filters) + MaxPooling2D
    *   Conv2D (128 filters) + MaxPooling2D
    *   Flatten Layer
    *   Dense Layer (512 units, ReLU activation)
    *   Dropout Layer (0.5 rate)
    *   Output Dense Layer (1 unit, Sigmoid activation for binary classification)
*   **Compilation:** Compiled using the `adam` optimizer and `binary_crossentropy` loss function, tracking `accuracy`.

## Usage

1.  **Environment:** Ensure you have Python and the required packages installed (listed above). A GPU is recommended for faster training.
2.  **Run the Notebook:** Open and run the `forest_fire_detection.ipynb` notebook cell by cell.
3.  **Dataset Download:** The notebook will automatically attempt to download the dataset using `kagglehub`. If this fails or you're in an environment without Kaggle API access (like standard Colab without setup), you might need to manually download the dataset from Kaggle and adjust the `DATASET_BASE_PATH` variable accordingly.
4.  **Training & Evaluation:** The notebook trains the model, plots accuracy/loss graphs, evaluates performance on the test set (including a confusion matrix and classification report), and saves the trained model (`wildfire_detection_model.keras`).
5.  **Prediction:** The final cells load the saved model and demonstrate how to predict on a single image using the `predict_fire` function.
